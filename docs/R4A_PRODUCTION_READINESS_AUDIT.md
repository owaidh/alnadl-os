## 2. حواجز الإطلاق المُثبَتة

### 🔴 PB-1 — الحاوية الإنتاجية لا تحتوي المهاجرات · **CRITICAL**

**Evidence**
```
Dockerfile:
  COPY server.js db.js ./
  COPY lib ./lib
  COPY public ./public
        ← migrations/ غير منسوخ إطلاقًا
```
و`lib/migrate.js:36` — `if (!fs.existsSync(MIGRATIONS_DIR)) return [];` **تعود صامتة** بدل الفشل.

**Reproduction** (نُفِّذت فعليًا)
```
نسخ ما ينسخه Dockerfile فقط ← تشغيل NODE_ENV=production
النتيجة: "Production bootstrap: created initial SuperAdmin" ثم:
  Error: no such table: engage_outbox
  at processOutboxOnce (lib/engage-worker.js:70)
الجداول: 37 فقط — مقابل 63 عند وجود migrations
مفقودة: branding_overrides · user_activation_tokens ·
        verification_challenges · refunds · engage_pass
```

**Impact**: النظام **يُقلع ثم ينهار خلال ثوانٍ**. لا تفعيل مستخدم · لا تحقق · لا استرجاعات · لا Engage · **لا White Label** — أي أن كل ما أُنجز في R1→R4 غائب في الإنتاج. والأسوأ أن الإقلاع يبدو ناجحًا في السطر الأول، فيُخفي العطل.

**Severity**: **PRODUCTION BLOCKER** — النظام غير صالح للتشغيل.

**Recommended Fix**: `COPY migrations ./migrations` في Dockerfile، **و** جعل غياب المجلد خطأ إقلاع صريحًا بدل عودة صامتة.

### 🔴 PB-2 — محدّد المعدل يُتجاوَز بترويسة مُزوَّرة · **SECURITY / HIGH**

**Evidence**: `lib/rate-limit.js:78` يقرأ `x-forwarded-for` **بلا أي تحقق من كون الوكيل موثوقًا**. `grep -c "TRUSTED_PROXY"` = **صفر في كل الملفات**.

**Reproduction** (نُفِّذت فعليًا على نقطة التحقق: 5 طلبات/5 دقائق)
```
بلا ترويسة:            200 200 200 200 200 429 429 429   ← يعمل
مع XFF مُزوَّر متغيّر:   200 200 200 200 200 200 200 200   ← تجاوز كامل
```

**Impact**: كل بوابات محدّد المعدل قابلة للتعطيل بسطر واحد. الأخطر على `verification` (تخمين OTP وإساءة كلفة الرسائل مستقبلًا) و`engage_discovery` (تخمين رموز القدرة) و`loyalty_lookup` (تعداد أرقام الجوال).

**Severity**: **SECURITY** — تجاوز كامل لضابط أمني قائم.

**Recommended Fix**: قراءة `X-Forwarded-For` **فقط** حين يأتي الطلب من وكيل ضمن قائمة موثوقة (`TRUSTED_PROXY_IPS`)، وإلا استخدام عنوان المقبس. التقصير في الإنتاج يجب أن يكون **عدم الثقة**.

### 🔴 PB-3 — تعدد النسخ غير مدعوم · **HIGH**

**Evidence**: حالة في الذاكرة لا تُشارَك:
- `lib/rate-limit.js:48` — `this.hits = new Map()`
- `lib/auth.js:53` — `const loginAttempts = new Map()`

**Impact**: عند N نسخة يصبح الحد الفعلي **N × الحد المُعلَن**، وحماية الدخول القاسية تنهار بالمثل. `APP_INSTANCES` يُحذّر عند الإقلاع لكنه **لا يمنع**.

**Severity**: **PRODUCTION BLOCKER لتعدد النسخ فقط** — ونسخة واحدة تعمل بشكل صحيح.

> **نتيجة إيجابية مهمة**: **الجلسات بلا حالة** (HMAC موقّعة، `lib/auth.js:sign`) — فلا تحتاج مخزنًا مشتركًا. المشكلة محصورة في العدّادات لا في الهوية.

**Recommended Fix**: مخزن مشترك (Redis) للعدّادات، **أو** الإطلاق بنسخة واحدة صراحةً مع توثيق الحد.
